Set up in this order

  1. Create a Supabase project and run database/setup.sql. Create and confirm your owner sign-in.
  2. Deploy the complete project to Netlify through a Git repository or Netlify CLI. The supplied netlify.toml configures the build. Uploading only the public folder is insufficient.
  3. Enter the private settings listed in .env.example into Netlify. Use test payment keys first.
  4. Configure the Razorpay payment and refund webhook. Test bookings and refunds before using live keys.
  5. In the owner desk, review tariffs, guest limits and cancellation policy. Open only the room nights intended for website sale.
  6. Add the book subdomain in Netlify and its CNAME at your DNS provider. Update the exact site URL setting, activate HTTPS and switch the gateway webhook to the final address.
  7. Connect your existing Hostinger Book Now buttons using the supplied link/form. Detailed steps are in README.md.

Yanolja remains manually updated. A separate website room allocation helps prevent simultaneous sales through the website and OTAs. Mark “CM updated” after each direct booking or cancellation.

Try it locally

With Node.js 22 or later, open this folder in a terminal, run npm ci, then npm run dev. Open http://127.0.0.1:8787. The sample owner desk is at /admin. Demo payments are simulated and clearly labelled.
